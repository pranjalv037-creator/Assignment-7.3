Assignment 7.3 — Responsive Product Listing

Aim

To create a responsive product listing webpage with six product cards using CSS Flexbox and flexible sizing properties.

Flexbox Properties Used

- "display: flex" — Arranges product cards in a flexible layout.
- "flex-wrap: wrap" — Allows cards to move to the next line when space is limited.
- "justify-content: center" — Centers the product cards horizontally.
- "align-items: stretch" — Stretches cards along the cross axis.
- "gap" — Adds spacing between product cards.
- "flex-grow: 1" — Allows cards to grow when extra space is available.
- "flex-shrink: 1" — Allows cards to shrink when necessary.
- "flex-basis: 250px" — Sets the initial size of each product card.

Features

- Six product cards with images, names, prices, and buttons.
- Responsive layout for desktop, tablet, and mobile screens.
- Flexbox wrapping and flexible card sizing.
- Hover effects on product cards and buttons.
- Product images displayed using "object-fit: cover".

Files Included

- "index.html" — HTML structure of the product listing.
- "style.css" — Flexbox layout, product styling, and responsive design.
- Desktop and mobile screenshots — Captured after opening the webpage in a browser at different screen widths.
